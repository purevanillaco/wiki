## 1. Commands
| Command | Description |
| --- | --- |
| [item] [inventory] [enderchest] | Using [item] displays the item you are holding in the chat, so other players can see it; the same applies to other commands. |
| /balance [name] - /balance top | Check your or player gem balance - View the server top gem holders. |
| /bite /boi /boop /dab /kiss /punch /slap /spin etc... | Interact with the players; there are more commands, but listing them all would spoil the fun of discovering them for yourselves. |
| /chatcolor | Command to change your chat text color; remember that you receive one color for [voting](https://purevanilla.co/vote), and the rest are for having the [Booster role](https://purevanilla.co/shop/booster). |
| /pay [name] [amount] | Pay gems to a player |
| /pvp | Enable or Disable PvP |



## 2 Rank Perks
Remember that ranks with perks can be obtained either with real money or by voting for the server. You can check the commands unlocked based on rank [here](https://purevanilla.co/shop/allay).
| Command | Description |
| --- | --- |
| /anvil | Virtual anvil. |
| /autoreplant | To use this you need to have a hoe in hand; you automatically replant the seeds. |

| /grindstone | Virtual Grindstone |

| /loom | Virtual loom. |

| /phantoms | Disabled. phantoms. |

| /stonecutter | Virtual stonecutter |
